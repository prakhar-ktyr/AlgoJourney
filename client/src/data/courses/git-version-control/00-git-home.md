# Git & Version Control

Welcome to the definitive **Git & Version Control** tutorial.

Version control is the invisible infrastructure of the software industry. Whether you are building an independent hobby project or contributing to the Linux Kernel alongside thousands of developers, Git is the tool that coordinates that effort.

Unlike basic tutorials that just give you a list of commands to memorize, this course is designed to take you from a complete novice to an absolute master by explaining **how Git actually works under the hood**.

When you understand the underlying mathematics and data structures of Git, the commands become intuitive, and recovering from seemingly catastrophic mistakes becomes trivial.

## What You Will Learn

This exhaustive course is broken down into critical sections:

- **Theory & Internals**: The `.git` directory, SHA-1 hashes, Directed Acyclic Graphs (DAGs), and the Object Database.
- **The Core Workflow**: The Three Trees architecture (Working Directory, Staging Area, HEAD), committing, and ignoring files.
- **Inspecting History**: Advanced `git log` formatting, `git diff`, and `git blame`.
- **Branching & Merging**: How branch pointers work, fast-forward vs 3-way merges, and complex conflict resolution.
- **Remote Repositories**: Managing remote tracking branches, fetching, pulling, and pushing.
- **Rewriting History**: Deep dive into `git reset` (--soft, --mixed, --hard), `git revert`, and Interactive Rebasing.
- **Advanced Mechanics**: `git reflog` recovery, `git cherry-pick`, `git bisect`, and `git worktree`.
- **Enterprise Workflows**: GitFlow, Trunk-based development, Git Hooks, and Submodules.

## Prerequisites

- **Command Line Comfort**: You should know how to open a terminal (or Git Bash on Windows), navigate directories (`cd`), and list files (`ls` or `dir`).
- **No programming language required**: Git works on text files, regardless of what language they are written in.

## How to use this Tutorial?

Because Git builds concepts sequentially, we highly recommend following the lessons in order, starting with **What is Git?**.

We will be diving deep. Open your terminal, initialize an empty repository, and follow along with the commands to see the internal mechanics update in real-time. Let's begin.
