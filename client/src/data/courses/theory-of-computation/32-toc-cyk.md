# CYK Parsing Algorithm

In this lesson, you will learn the **Cocke-Younger-Kasami (CYK) algorithm** — a dynamic programming method that determines whether a string $w$ belongs to the language generated by a context-free grammar $G$. This algorithm proves that the **membership problem for CFLs is decidable** in polynomial time.

---

## The Membership Problem

Given a context-free grammar $G$ and a string $w$, does $w \in L(G)$?

This is a fundamental question. For regular languages, we just simulate a DFA. But for CFLs, we need a smarter approach because:

- Naive top-down parsing might loop forever (left recursion)
- Brute-force derivation enumeration is exponential
- We need a systematic method

**CYK** solves this in $O(n^3 \cdot |G|)$ time, where $n = |w|$.

---

## Prerequisites

The CYK algorithm requires the grammar to be in **Chomsky Normal Form (CNF)**.

Recall that in CNF, every production has one of two forms:

$$A \to BC \quad \text{(two variables)}$$
$$A \to a \quad \text{(single terminal)}$$

If $\varepsilon \in L(G)$, we also allow $S \to \varepsilon$ (but $S$ cannot appear on the right side of any production).

**Why CNF?** Because in CNF:
- Every derivation of a string of length $n$ takes exactly $2n - 1$ steps
- Every internal node in the parse tree has exactly 2 children
- This binary structure enables the dynamic programming approach

If your grammar isn't in CNF, convert it first (see Lesson 25).

---

## The Key Idea

CYK fills a **triangular table** $T$ where:

$$T[i][j] = \{ A \in V \mid A \Rightarrow^* w_i w_{i+1} \cdots w_j \}$$

In words: $T[i][j]$ contains all variables that can generate the substring from position $i$ to position $j$.

The string $w \in L(G)$ if and only if the start symbol $S$ is in $T[1][n]$ (the cell representing the entire string).

---

## Algorithm Details

### Input

- A CNF grammar $G = (V, \Sigma, R, S)$
- A string $w = w_1 w_2 \cdots w_n$ of length $n$

### The Table

We build a 2D table $T[i][j]$ for $1 \leq i \leq j \leq n$.

Think of it as an upper-triangular matrix (or a triangle):

```
        j →
      1   2   3   4   5
i  1 [1,1][1,2][1,3][1,4][1,5]  ← goal: S ∈ T[1][5]?
↓  2      [2,2][2,3][2,4][2,5]
   3           [3,3][3,4][3,5]
   4                [4,4][4,5]
   5                     [5,5]
```

### Base Case (Diagonal: substrings of length 1)

For each position $i$ ($1 \leq i \leq n$):

$$T[i][i] = \{ A \in V \mid A \to w_i \in R \}$$

Simply look up which variables have a production that generates the single terminal $w_i$.

### Recursive Case (Substrings of length $\ell \geq 2$)

For each cell $T[i][j]$ where $j - i + 1 = \ell$ (substring length $\ell$):

$$T[i][j] = \bigcup_{k=i}^{j-1} \{ A \in V \mid \exists\, A \to BC \in R \text{ with } B \in T[i][k] \text{ and } C \in T[k+1][j] \}$$

We try every possible **split point** $k$ between $i$ and $j-1$:
- Left part: $w_i \cdots w_k$ (generated by some $B \in T[i][k]$)
- Right part: $w_{k+1} \cdots w_j$ (generated by some $C \in T[k+1][j]$)
- If there's a rule $A \to BC$, then $A$ goes into $T[i][j]$

### Decision

$$w \in L(G) \iff S \in T[1][n]$$

---

## Algorithm in Pseudocode

```
CYK(G, w):
    n = |w|
    
    // Base case: length-1 substrings
    for i = 1 to n:
        T[i][i] = { A | A → w_i ∈ R }
    
    // Fill table for increasing substring lengths
    for ℓ = 2 to n:                    // substring length
        for i = 1 to n - ℓ + 1:        // start position
            j = i + ℓ - 1              // end position
            T[i][j] = ∅
            for k = i to j - 1:        // split point
                for each rule A → BC in R:
                    if B ∈ T[i][k] and C ∈ T[k+1][j]:
                        T[i][j] = T[i][j] ∪ {A}
    
    // Decision
    return S ∈ T[1][n]
```

---

## Complexity Analysis

### Time Complexity

$$O(n^3 \cdot |R|)$$

- Three nested loops for $\ell$, $i$, $k$: $O(n^3)$
- For each split point, check all rules: $O(|R|)$
- Total: $O(n^3 \cdot |R|)$

Since $|R|$ is part of the grammar (fixed), we often write this as $O(n^3 \cdot |G|)$ or simply $O(n^3)$ for a fixed grammar.

### Space Complexity

$$O(n^2 \cdot |V|)$$

The table has $O(n^2)$ cells, each storing a subset of $V$ (at most $|V|$ variables per cell).

## Complete Example 1: String in Language

### Grammar

Let $G$ be in CNF with:

$$V = \{S, A, B, C\}$$
$$\Sigma = \{a, b\}$$

Productions:

$$S \to AB \mid BC$$
$$A \to BA \mid a$$
$$B \to CC \mid b$$
$$C \to AB \mid a$$

### Input String

$$w = \text{baaba} \quad (n = 5)$$

### Step 1: Base Case (Length 1)

| Position $i$ | $w_i$ | $T[i][i]$ | Explanation |
|:---:|:---:|:---:|:---|
| 1 | $b$ | $\{B\}$ | $B \to b$ |
| 2 | $a$ | $\{A, C\}$ | $A \to a$, $C \to a$ |
| 3 | $a$ | $\{A, C\}$ | $A \to a$, $C \to a$ |
| 4 | $b$ | $\{B\}$ | $B \to b$ |
| 5 | $a$ | $\{A, C\}$ | $A \to a$, $C \to a$ |

### Step 2: Length 2 Substrings

**$T[1][2]$:** Substring $ba$, split at $k=1$:
- $T[1][1] = \{B\}$, $T[2][2] = \{A, C\}$
- Check rules: $S \to BC$? $B \in T[1][1]$, $C \in T[2][2]$ ✓ → $S$
- Check: $A \to BA$? $B \in T[1][1]$, $A \in T[2][2]$ ✓ → $A$

$$T[1][2] = \{S, A\}$$

**$T[2][3]$:** Substring $aa$, split at $k=2$:
- $T[2][2] = \{A, C\}$, $T[3][3] = \{A, C\}$
- $S \to AB$? $A \in T[2][2]$ ✓, but $B \in T[3][3]$? No.
- $B \to CC$? $C \in T[2][2]$ ✓, $C \in T[3][3]$ ✓ → $B$

$$T[2][3] = \{B\}$$

**$T[3][4]$:** Substring $ab$, split at $k=3$:
- $T[3][3] = \{A, C\}$, $T[4][4] = \{B\}$
- $S \to AB$? $A \in T[3][3]$ ✓, $B \in T[4][4]$ ✓ → $S$
- $C \to AB$? $A \in T[3][3]$ ✓, $B \in T[4][4]$ ✓ → $C$

$$T[3][4] = \{S, C\}$$

**$T[4][5]$:** Substring $ba$, split at $k=4$:
- $T[4][4] = \{B\}$, $T[5][5] = \{A, C\}$
- $S \to BC$? $B \in T[4][4]$ ✓, $C \in T[5][5]$ ✓ → $S$
- $A \to BA$? $B \in T[4][4]$ ✓, $A \in T[5][5]$ ✓ → $A$

$$T[4][5] = \{S, A\}$$

### Step 3: Length 3 Substrings

**$T[1][3]$:** Substring $baa$, splits at $k=1$ and $k=2$:

$k=1$: $T[1][1] = \{B\}$, $T[2][3] = \{B\}$
- $B \to CC$? Need $C$ in both — no. No other matches.

$k=2$: $T[1][2] = \{S, A\}$, $T[3][3] = \{A, C\}$
- $S \to AB$? $A \in T[1][2]$ ✓, but $B \in T[3][3]$? No.
- $B \to CC$? $C \in T[1][2]$? No ($T[1][2] = \{S, A\}$). No matches.

$$T[1][3] = \emptyset$$

**$T[2][4]$:** Substring $aab$, splits at $k=2$ and $k=3$:

$k=2$: $T[2][2] = \{A, C\}$, $T[3][4] = \{S, C\}$
- $B \to CC$? $C \in T[2][2]$ ✓, $C \in T[3][4]$ ✓ → $B$

$k=3$: $T[2][3] = \{B\}$, $T[4][4] = \{B\}$
- No rule $? \to BB$. No matches.

$$T[2][4] = \{B\}$$

**$T[3][5]$:** Substring $aba$, splits at $k=3$ and $k=4$:

$k=3$: $T[3][3] = \{A, C\}$, $T[4][5] = \{S, A\}$
- $S \to AB$? $A$ ✓, $B \in T[4][5]$? No.
- No other matches from this split.

$k=4$: $T[3][4] = \{S, C\}$, $T[5][5] = \{A, C\}$
- $S \to AB$? Need $A \in T[3][4]$ — no.
- $S \to BC$? Need $B \in T[3][4]$ — no.
- $B \to CC$? $C \in T[3][4]$ ✓, $C \in T[5][5]$ ✓ → $B$

$$T[3][5] = \{B\}$$

### Step 4: Length 4 Substrings

**$T[1][4]$:** Substring $baab$, splits at $k=1,2,3$:

$k=1$: $T[1][1] = \{B\}$, $T[2][4] = \{B\}$
- No rule $? \to BB$.

$k=2$: $T[1][2] = \{S, A\}$, $T[3][4] = \{S, C\}$
- $B \to CC$? Need $C \in T[1][2]$ — no.
- $S \to BC$? Need $B \in T[1][2]$ — no.
- Hmm... Let me check: $A \to BA$? No, need $B$ and $A$.

Actually wait — no matches from this split.

$k=3$: $T[1][3] = \emptyset$, $T[4][4] = \{B\}$
- Empty left side, no matches.

$$T[1][4] = \emptyset$$

**$T[2][5]$:** Substring $aaba$, splits at $k=2,3,4$:

$k=2$: $T[2][2] = \{A, C\}$, $T[3][5] = \{B\}$
- $S \to AB$? $A \in T[2][2]$ ✓, $B \in T[3][5]$ ✓ → $S$
- $C \to AB$? $A \in T[2][2]$ ✓, $B \in T[3][5]$ ✓ → $C$

$k=3$: $T[2][3] = \{B\}$, $T[4][5] = \{S, A\}$
- $A \to BA$? $B \in T[2][3]$ ✓, $A \in T[4][5]$ ✓ → $A$

$k=4$: $T[2][4] = \{B\}$, $T[5][5] = \{A, C\}$
- $S \to BC$? $B \in T[2][4]$ ✓, $C \in T[5][5]$ ✓ → $S$ (already in)
- $A \to BA$? $B \in T[2][4]$ ✓, $A \in T[5][5]$ ✓ → $A$ (already in)

$$T[2][5] = \{S, A, C\}$$

### Step 5: Length 5 (Full String)

**$T[1][5]$:** String $baaba$, splits at $k=1,2,3,4$:

$k=1$: $T[1][1] = \{B\}$, $T[2][5] = \{S, A, C\}$
- $S \to BC$? $B$ ✓, $C \in T[2][5]$ ✓ → $S$
- $A \to BA$? $B$ ✓, $A \in T[2][5]$ ✓ → $A$

$k=2$: $T[1][2] = \{S, A\}$, $T[3][5] = \{B\}$
- $S \to AB$? $A \in T[1][2]$ ✓, $B \in T[3][5]$ ✓ → $S$ (already in)
- $C \to AB$? $A$ ✓, $B$ ✓ → $C$

$k=3$: $T[1][3] = \emptyset$, $T[4][5] = \{S, A\}$
- No matches (left side empty).

$k=4$: $T[1][4] = \emptyset$, $T[5][5] = \{A, C\}$
- No matches (left side empty).

$$T[1][5] = \{S, A, C\}$$

### Result

Since $S \in T[1][5]$, the string **baaba** is in $L(G)$. ✓

### Complete Table

```
     1       2       3       4       5
1  {B}    {S,A}    ∅       ∅     {S,A,C}
2        {A,C}   {B}     {B}    {S,A,C}
3               {A,C}  {S,C}     {B}
4                       {B}     {S,A}
5                              {A,C}
```

## Complete Example 2: String NOT in Language

### Same Grammar, Input: $w = bba$

$n = 3$

**Base case:**
- $T[1][1] = \{B\}$ ($b$)
- $T[2][2] = \{B\}$ ($b$)
- $T[3][3] = \{A, C\}$ ($a$)

**Length 2:**

$T[1][2]$: split $k=1$: $T[1][1]=\{B\}$, $T[2][2]=\{B\}$
- No rule $? \to BB$. → $T[1][2] = \emptyset$

$T[2][3]$: split $k=2$: $T[2][2]=\{B\}$, $T[3][3]=\{A,C\}$
- $S \to BC$? $B$ ✓, $C$ ✓ → $S$
- $A \to BA$? $B$ ✓, $A$ ✓ → $A$
- → $T[2][3] = \{S, A\}$

**Length 3:**

$T[1][3]$: splits $k=1,2$:

$k=1$: $T[1][1]=\{B\}$, $T[2][3]=\{S,A\}$
- $A \to BA$? $B$ ✓, $A$ ✓ → $A$

$k=2$: $T[1][2]=\emptyset$, $T[3][3]=\{A,C\}$
- No matches.

$$T[1][3] = \{A\}$$

**Decision:** $S \notin T[1][3]$, so **bba** is NOT in $L(G)$. ✗

## Recovering the Parse Tree

The basic CYK algorithm only answers yes/no. To recover **how** the string is derived (the parse tree), we store **backpointers**.

### Modified Algorithm

For each entry $A \in T[i][j]$, also store:
- The split point $k$ that produced it
- The rule $A \to BC$ used
- Which $B \in T[i][k]$ and $C \in T[k+1][j]$ were matched

### Backtracking

To build the parse tree for $S \in T[1][n]$:

```
BuildTree(A, i, j):
    if i == j:
        return leaf node (A → w_i)
    else:
        retrieve (k, A → BC) from backpointer for A in T[i][j]
        leftTree = BuildTree(B, i, k)
        rightTree = BuildTree(C, k+1, j)
        return tree with root A, left child leftTree, right child rightTree
```

### Ambiguity

If a variable $A$ enters $T[i][j]$ via **multiple** split points or rules, the grammar is **ambiguous** for this string — there are multiple parse trees. CYK can find all of them.

---

## Why CYK Matters

### 1. Decidability

CYK proves a fundamental theorem:

> **Theorem:** The membership problem for context-free languages is decidable.

Given any CFG $G$ and string $w$, we can:
1. Convert $G$ to CNF (always possible)
2. Run CYK
3. Get a definitive yes/no answer in finite time

### 2. Polynomial Time

The membership problem is not just decidable — it's solvable in **polynomial time** $O(n^3)$. This is vastly better than exponential brute-force methods.

### 3. Natural Language Processing

CYK is used in computational linguistics to parse natural language sentences according to formal grammars. Given a grammar for English (simplified), CYK determines all valid parse trees for a sentence.

### 4. Compiler Design

While real compilers use faster specialized parsers (LL, LR), CYK serves as a theoretical foundation and fallback for ambiguous grammars.

---

## Earley Parser (Brief Mention)

**Earley's algorithm** (1970) is an alternative parsing method that:

- Works with **any** CFG (not just CNF)
- Runs in $O(n^3)$ worst case
- Runs in $O(n^2)$ for unambiguous grammars
- Runs in $O(n)$ for most practical (LR) grammars

It uses a chart-based approach with prediction, scanning, and completion steps. Earley's algorithm is more practical than CYK for real applications because it doesn't require CNF conversion.

## Summary

| Aspect | Detail |
|--------|--------|
| Input | CNF grammar $G$, string $w$ of length $n$ |
| Output | Yes/No: is $w \in L(G)$? |
| Method | Dynamic programming on substrings |
| Table | $T[i][j]$ = variables generating $w_i \cdots w_j$ |
| Base | $T[i][i] = \{A \mid A \to w_i\}$ |
| Recurse | $T[i][j] = \bigcup_k \{A \mid A \to BC, B \in T[i][k], C \in T[k+1][j]\}$ |
| Accept | $S \in T[1][n]$ |
| Time | $O(n^3 \cdot |G|)$ |
| Space | $O(n^2 \cdot |V|)$ |
| Prerequisite | Grammar must be in CNF |
