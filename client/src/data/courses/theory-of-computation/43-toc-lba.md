# Linear Bounded Automata

In this lesson, we study the **Linear Bounded Automaton (LBA)** — a restricted Turing machine that uses only as much tape as the length of its input. LBAs are the computational model for **context-sensitive languages**, sitting between pushdown automata and unrestricted Turing machines in the Chomsky hierarchy.

---

## Why LBAs Matter

LBAs fill a crucial gap:

$$
\text{DFA/NFA} \subset \text{PDA} \subset \text{LBA} \subset \text{TM}
$$

Many practical languages (like $\{a^n b^n c^n\}$) are context-sensitive but not context-free. LBAs recognize exactly these languages.

---

## Definition of a Linear Bounded Automaton

An **LBA** is a nondeterministic Turing machine with one restriction:

> The tape head **never moves beyond** the portion of the tape containing the input.

### Formal Definition

An LBA is a tuple $M = (Q, \Sigma, \Gamma, \delta, q_0, q_{accept}, q_{reject})$ where:

- $Q$ is a finite set of states
- $\Sigma$ is the input alphabet (not containing the blank symbol)
- $\Gamma \supseteq \Sigma$ is the tape alphabet (includes endmarkers)
- $\delta: Q \times \Gamma \to \mathcal{P}(Q \times \Gamma \times \{L, R\})$ is the transition function
- $q_0 \in Q$ is the start state
- $q_{accept} \in Q$ is the accept state
- $q_{reject} \in Q$ is the reject state ($q_{reject} \neq q_{accept}$)

### The Tape Restriction

The input $w = w_1 w_2 \cdots w_n$ is placed on the tape between **endmarkers**:

$$
\triangleright \; w_1 \; w_2 \; \cdots \; w_n \; \triangleleft
$$

- $\triangleright$ = left endmarker
- $\triangleleft$ = right endmarker

**Rule:** The head may never move left of $\triangleright$ or right of $\triangleleft$. The endmarkers may not be overwritten.

### What This Means

- The LBA has exactly $n$ usable tape cells (where $n = |w|$)
- It can read and write on these cells
- It can move left and right within this bounded region
- It CANNOT extend the tape beyond the input

> **Think of it as:** A Turing machine in a box — it has all the computational power of a TM, but is trapped within $O(n)$ space.

---

## Nondeterminism in LBAs

LBAs are inherently **nondeterministic**:

$$
\delta: Q \times \Gamma \to \mathcal{P}(Q \times \Gamma \times \{L, R\})
$$

The transition function returns a **set** of possible next moves. The LBA accepts if ANY computation path leads to $q_{accept}$.

> **Note:** It is an open question whether deterministic LBAs (DLBAs) are as powerful as nondeterministic LBAs. This is the **LBA problem** — one of the oldest open problems in theoretical CS.

$$
\text{DLBA} \stackrel{?}{=} \text{LBA}
$$

---

## Context-Sensitive Languages (CSLs)

The class of languages recognized by LBAs is exactly the class of **context-sensitive languages**.

### Context-Sensitive Grammar (CSG)

A grammar $G = (V, \Sigma, R, S)$ is **context-sensitive** if every production rule has the form:

$$
\alpha A \beta \to \alpha \gamma \beta
$$

where:
- $A \in V$ (a single variable)
- $\alpha, \beta \in (V \cup \Sigma)^*$ (the "context")
- $\gamma \in (V \cup \Sigma)^+$ (the replacement, non-empty)

### Key Property: Monotonic

In a context-sensitive grammar, no rule **shrinks** the sentential form:

$$
|\alpha A \beta| \leq |\alpha \gamma \beta|
$$

Since $|\gamma| \geq 1$ and we replace a single $A$ with $\gamma$:

$$
|\text{LHS}| \leq |\text{RHS}|
$$

This means derivations can only grow (or stay the same length). This is why the tape doesn't need to grow — the working space is bounded by the length of the derivation target.

### The Exception: Empty String

Strictly, a CSG cannot generate $\varepsilon$ (since rules are non-shrinking). The convention is:

- Allow $S \to \varepsilon$ ONLY if $S$ does not appear on the right side of any rule
- This is a minor technical point

---

## LBA ↔ CSG Equivalence

> **Theorem:** A language $L$ is recognized by an LBA if and only if $L$ is generated by a context-sensitive grammar.

$$
L \text{ is context-sensitive} \iff L \text{ is recognized by some LBA}
$$

### Proof Sketch (CSG → LBA)

Given a CSG $G$, build an LBA that on input $w$:
1. Nondeterministically guess a derivation $S \Rightarrow^* w$
2. Start with $w$ on the tape
3. At each step, nondeterministically choose a rule and apply it **in reverse**
4. If the tape contains only $S$, accept
5. If no reverse rule applies and tape ≠ $S$, reject

Since rules are monotonic, reverse derivation can only shrink the string, so it stays within the tape bounds.

### Proof Sketch (LBA → CSG)

Given an LBA $M$, construct a CSG that simulates $M$'s computation. The variables encode configurations (state + tape contents + head position). This is complex but constructive.

## Examples of Context-Sensitive Languages

### Example 1: $\{a^n b^n c^n \mid n \geq 1\}$

This is the classic language that is context-sensitive but NOT context-free.

**Why it's not CFL:** The pumping lemma for CFLs fails (proved in earlier lesson).

**LBA recognition:**

On input $w$:
1. Check that $w$ has the form $a^+ b^+ c^+$ (reject otherwise)
2. Repeat:
   - Cross off one $a$, one $b$, and one $c$ (mark them)
3. If all symbols are crossed off → accept
4. If counts don't match at any point → reject

This works in $O(n^2)$ steps using only $n$ tape cells.

**CSG for $\{a^n b^n c^n\}$:**

$$
\begin{aligned}
S &\to aSBC \mid aBC \\
CB &\to BC \\
aB &\to ab \\
bB &\to bb \\
bC &\to bc \\
cC &\to cc
\end{aligned}
$$

> **Note:** The rule $CB \to BC$ is technically not in standard CSG form. It can be converted using intermediate variables.

---

### Example 2: $\{ww \mid w \in \{a, b\}^*\}$

The language of "double copies" — strings that are the concatenation of a string with itself.

**Why it's not CFL:** Pumping lemma fails.

**LBA recognition:**

On input $x$ (where $|x| = 2n$):
1. If $|x|$ is odd, reject
2. Mark the middle of the string (find it by alternately marking from both ends)
3. Compare the first half with the second half, symbol by symbol
4. Accept if they match, reject otherwise

All of this fits within $|x|$ tape cells.

---

### Example 3: $\{a^{n!} \mid n \geq 1\}$

Strings of $a$'s whose length is a factorial number: $1, 2, 6, 24, 120, \ldots$

**LBA recognition:**

On input $a^m$:
1. Try $n = 1, 2, 3, \ldots$
2. For each $n$, compute $n!$ using the tape
3. If $n! = m$, accept
4. If $n! > m$, reject

Since $n! \leq m$ implies $n \leq m$ (roughly), we only try $O(m)$ values of $n$. Each factorial computation uses $O(\log m)$ space... but we have $m$ cells, which is more than enough.

---

### Example 4: $\{a^{2^n} \mid n \geq 0\}$

Strings of $a$'s whose length is a power of 2: $1, 2, 4, 8, 16, \ldots$

**LBA recognition:**

On input $a^m$:
1. If $m = 1$, accept
2. If $m$ is odd (and $> 1$), reject
3. Cross off every other $a$ (halving the count)
4. Repeat from step 1 with the remaining $a$'s

Each halving stays within the tape. If we reach exactly 1, accept.

## LBA Decidability Results

### Membership is Decidable

> **Theorem:** Given an LBA $M$ and string $w$, it is decidable whether $M$ accepts $w$.

$$
A_{LBA} = \{\langle M, w \rangle \mid M \text{ is an LBA that accepts } w\} \text{ is decidable}
$$

**Proof:**

The key insight is that an LBA on input of length $n$ has a **bounded number of configurations**.

A configuration of an LBA consists of:
- Current state: $|Q|$ choices
- Head position: $n$ choices (restricted to input cells)
- Tape contents: $|\Gamma|^n$ choices

Total configurations:

$$
C = |Q| \cdot n \cdot |\Gamma|^n
$$

This is a **finite** number for any fixed input!

**Algorithm:**

On input $\langle M, w \rangle$ (where $|w| = n$):
1. Compute $C = |Q| \cdot n \cdot |\Gamma|^n$
2. Simulate $M$ on $w$ for at most $C$ steps (on each nondeterministic branch)
3. If any branch accepts within $C$ steps → accept
4. Otherwise → reject

**Why this works:** If $M$ hasn't halted within $C$ steps, it must have repeated a configuration (pigeonhole principle), meaning it's in a loop. Since $M$ is nondeterministic, we explore all branches.

---

### Emptiness is Undecidable

> **Theorem:** The emptiness problem for LBAs is undecidable.

$$
E_{LBA} = \{\langle M \rangle \mid M \text{ is an LBA with } L(M) = \emptyset\} \text{ is undecidable}
$$

**Proof idea:** Reduce from $A_{TM}$. Given $\langle M, w \rangle$, construct an LBA $B$ that accepts a string $x$ iff $x$ encodes an accepting computation history of $M$ on $w$. Then:

- $M$ accepts $w$ $\iff$ $B$ accepts some string $\iff$ $L(B) \neq \emptyset$

So deciding $E_{LBA}$ would decide $A_{TM}$, which is impossible.

---

### Summary of LBA Decidability

| Problem | Status |
|---------|--------|
| Membership ($A_{LBA}$) | **Decidable** |
| Emptiness ($E_{LBA}$) | Undecidable |
| Equivalence ($EQ_{LBA}$) | Undecidable |
| Universality ($ALL_{LBA}$) | Undecidable |
| Finiteness | Undecidable |

---

## Configuration Counting in Detail

For input length $n$, the number of possible LBA configurations is:

$$
|Q| \cdot n \cdot |\Gamma|^n
$$

Let's break this down:

- **State component:** The LBA can be in any of $|Q|$ states
- **Head position:** The head can be at any of the $n$ tape positions
- **Tape contents:** Each of the $n$ cells can hold any of $|\Gamma|$ symbols

### Example Calculation

For $|Q| = 10$, $|\Gamma| = 5$, $n = 3$:

$$
C = 10 \cdot 3 \cdot 5^3 = 10 \cdot 3 \cdot 125 = 3750
$$

So an LBA with these parameters on a 3-symbol input can have at most 3750 distinct configurations. If it runs for more than 3750 steps without halting, it's looping.

### Why This Makes Membership Decidable

Since configurations are finite:
- The computation graph (where nodes are configurations and edges are transitions) is **finite**
- We can explore it completely
- We can determine if any accepting configuration is reachable from the start

This is fundamentally different from unrestricted TMs, where the tape (and thus the number of configurations) is unbounded.

---

## LBA vs Turing Machine

| Feature | LBA | TM |
|---------|-----|-----|
| Tape | Bounded by input length | Unbounded |
| Nondeterminism | Yes (standard) | Yes (but deterministic suffices) |
| Membership decidable? | **Yes** | No ($A_{TM}$ undecidable) |
| Emptiness decidable? | No | No |
| Power | Context-sensitive languages | R.E. languages |
| Configurations on input $n$ | Finite: $|Q| \cdot n \cdot |\Gamma|^n$ | Infinite |

### Why the Restriction Helps

The bounded tape gives LBAs a crucial property: **every computation either halts or cycles**. This is because:

1. There are finitely many configurations
2. The computation is deterministic from each configuration (in each nondeterministic branch)
3. By the pigeonhole principle, if the machine runs for more than $C$ steps, it revisits a configuration

For unrestricted TMs, the tape can grow indefinitely, creating an infinite configuration space — and we can never be sure if the machine will eventually halt.

## Position in the Chomsky Hierarchy

LBAs correspond to **Type 1** in the Chomsky hierarchy:

| Type | Grammar | Automaton | Languages |
|------|---------|-----------|-----------|
| 3 | Right-linear | DFA/NFA | Regular |
| 2 | Context-free ($A \to \alpha$) | PDA | Context-free |
| **1** | **Context-sensitive** | **LBA** | **Context-sensitive** |
| 0 | Unrestricted | TM | Recursively enumerable |

### Strict Containments

$$
\text{Regular} \subsetneq \text{CFL} \subsetneq \text{CSL} \subsetneq \text{Recursive} \subsetneq \text{R.E.}
$$

Each containment is strict:
- $\{a^n b^n\}$ is CFL but not regular
- $\{a^n b^n c^n\}$ is CSL but not CFL
- $A_{TM}$ is R.E. but not recursive (hence not CSL, since all CSLs are decidable by the membership theorem)

### CSL ⊂ Decidable

Every context-sensitive language is decidable! This follows from:
- LBAs have bounded configurations
- Membership is decidable for LBAs
- Therefore CSL ⊆ Decidable

The containment is strict: there exist decidable languages that are not context-sensitive (e.g., some languages requiring more than linear space).

---

## The Open LBA Problem

One of the oldest open problems in theoretical computer science:

> **Open Problem:** Is $\text{DLBA} = \text{LBA}$?

That is: can every nondeterministic LBA be simulated by a deterministic LBA?

This is analogous to:
- NFA = DFA (for regular languages — TRUE)
- NPDA ≠ DPDA (for context-free languages — nondeterminism helps)
- NTM = DTM (for Turing machines — TRUE, both recognize R.E.)

For LBAs, we don't know! The corresponding language class question is:

> Are deterministic context-sensitive languages the same as context-sensitive languages?

This is related to (but distinct from) the $P \stackrel{?}{=} NP$ question.

---

## Space Complexity Connection

LBAs are actually Turing machines restricted to use **linear space**:

$$
\text{LBA} = \text{NSPACE}(n)
$$

This connects to space complexity theory:

- $\text{NSPACE}(n)$ = languages decided by NTMs using $O(n)$ tape cells
- CSL = $\text{NSPACE}(n)$ (Immerman–Szelepcsényi theorem implies CSL is closed under complement)

More generally:
- $\text{DSPACE}(n)$ = deterministic linear space (what DLBAs recognize)
- Open: $\text{DSPACE}(n) \stackrel{?}{=} \text{NSPACE}(n)$

## Try It Yourself

### Exercise 1

Design an LBA that recognizes $\{a^n b^n c^n \mid n \geq 1\}$. Describe the algorithm.

<details>
<summary>Solution</summary>

LBA $M$ on input $w$:
1. Scan to verify $w = a^* b^* c^*$ (reject if not)
2. Repeat until all symbols are marked:
   a. Scan right, find the first unmarked $a$, mark it (e.g., replace with $X$)
   b. Continue right, find the first unmarked $b$, mark it (replace with $Y$)
   c. Continue right, find the first unmarked $c$, mark it (replace with $Z$)
   d. If any step fails to find the needed symbol, reject
3. After marking, scan to verify no unmarked symbols remain
4. Accept

This uses only the input tape (no extra space beyond $n$ cells).

</details>

### Exercise 2

How many configurations does an LBA with 5 states, tape alphabet $\{a, b, c, \sqcup, X, Y\}$ have on input of length 10?

<details>
<summary>Solution</summary>

$$
C = |Q| \cdot n \cdot |\Gamma|^n = 5 \cdot 10 \cdot 6^{10} = 50 \cdot 60,\!466,\!176 = 3,\!023,\!308,\!800
$$

About 3 billion configurations. The membership algorithm would need to explore this many possibilities in the worst case.

</details>

### Exercise 3

Prove that every context-free language is also context-sensitive.

<details>
<summary>Solution</summary>

A CFG has rules of the form $A \to \alpha$ where $A$ is a variable and $\alpha \in (V \cup \Sigma)^*$.

For the CSG requirement $\alpha A \beta \to \alpha \gamma \beta$ with $|\gamma| \geq 1$:
- Take each CFG rule $A \to \alpha$ where $|\alpha| \geq 1$
- This is already in CSG form (with empty context: $\alpha = \beta = \varepsilon$)

The only problem is rules $A \to \varepsilon$ (which shrink the sentential form). But we can eliminate $\varepsilon$-productions using the standard algorithm (except possibly $S \to \varepsilon$ with $S$ not on any RHS).

Therefore every CFL (except possibly $\{\varepsilon\}$) has a CSG. ∎

</details>

### Exercise 4

Why is $A_{TM}$ not a context-sensitive language?

<details>
<summary>Solution</summary>

All context-sensitive languages are decidable (because LBA membership is decidable). But $A_{TM}$ is undecidable. Therefore $A_{TM}$ is not context-sensitive.

More precisely: CSL ⊂ Decidable ⊂ R.E., and $A_{TM} \in$ R.E. but $A_{TM} \notin$ Decidable, so $A_{TM} \notin$ CSL.

</details>

### Exercise 5

Is $\{a^p \mid p \text{ is prime}\}$ a context-sensitive language?

<details>
<summary>Solution</summary>

Yes! We can build an LBA that checks if the input length is prime:

On input $a^n$:
1. If $n \leq 1$, reject
2. For $d = 2, 3, \ldots, \lfloor\sqrt{n}\rfloor$:
   - Check if $d$ divides $n$ (by repeatedly marking groups of $d$ symbols)
   - If $d | n$, reject
3. If no divisor found, accept

The trial division can be done within $n$ tape cells (we only need to store the current divisor and perform the division check on the tape). Therefore this language is context-sensitive.

</details>

## Key Takeaways

1. **LBA** = NTM with tape bounded by input length (endmarkers $\triangleright$, $\triangleleft$)
2. **LBA ↔ CSG**: LBAs recognize exactly the context-sensitive languages
3. **Membership is decidable**: bounded tape → finite configurations → halt or cycle detection
4. **Configurations**: $|Q| \cdot n \cdot |\Gamma|^n$ (finite for fixed input)
5. **Emptiness is undecidable**: despite bounded tape!
6. **Hierarchy**: Regular ⊂ CFL ⊂ CSL ⊂ Decidable ⊂ R.E.
7. **Open problem**: Does DLBA = LBA?
